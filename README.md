# קו בינה מלאכותית אישי

ימות המשיח + Gemini + Render. המתקשר מקליט שאלה, Gemini עונה, והתשובה מוקראת בקו.

## תפריט ראשי
- **1** – הקלטת שאלה (בסיום מקישים #)
- **5** – הזנת הסיסמה שהוגדרה ב-BYPASS_PASSWORD לביטול הסינון בשיחה הנוכחית. הקשה חוזרת של 5 וסיסמה מחזירה את הסינון. אחרי 3 ניסיונות שגויים האפשרות ננעלת לאותה שיחה.

## משתני סביבה ב-Render
| משתנה | ערך |
|---|---|
| `YEMOT_TOKEN` | `מספר_המערכת:סיסמה` (למשל `0771234567:1234`) או מפתח API מימות |
| `GEMINI_API_KEY` | מפתח מ-aistudio.google.com/apikey |
| `GEMINI_API_KEY_2` ... `GEMINI_API_KEY_10` | מפתחות נוספים (לא חובה) – כשהמכסה של מפתח נגמרת עוברים לבא. כל מפתח מחשבון/פרויקט גוגל אחר = מכסה נפרדת |
| `ADMIN_PASSWORD` | סיסמה לממשק הניהול |
| `BYPASS_PASSWORD` | סיסמת ביטול הסינון (חובה למקש 5) |
| `MAX_WORDS` | אורך תשובה מקסימלי (ברירת מחדל 80) |
| `BOT_STYLE` | סגנון הבוט, למשל `ידידותי ופשוט` |
| `WELCOME_TEXT` | משפט הפתיחה |

## הגדרת השלוחה בימות המשיח
בשלוחה הראשית (או בכל שלוחה), בקובץ `ext.ini`:
```
type=api
api_link=https://YOUR-APP.onrender.com/yemot
```

## ממשק ניהול
`https://YOUR-APP.onrender.com/admin` – שם משתמש: כל דבר, סיסמה: `ADMIN_PASSWORD`.
מציג כמות משתמשים, שיחות, שאלות, מספרי טלפון, וחסימה/שחרור של מספר.
הנתונים נשמרים בתוך מערכת ימות (`ai_data/users.ini`), כך שהם לא נמחקים כש-Render מופעל מחדש.

## הערה על Render בחינם
השרת "נרדם" אחרי 15 דקות בלי פעילות, ושיחה ראשונה אחרי זה עלולה להיכשל. אפשר להגדיר ב-UptimeRobot (בחינם) בדיקה כל 10 דקות לכתובת `/health`.
